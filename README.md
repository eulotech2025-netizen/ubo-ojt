# 우보브랜드샵 신입 교재

세 칸으로 된 신입 교재.

- **교재 — 주문 하나의 일생** (`textbook.html`): 0장 우리 회사 한 장 → 1~6장 견적 · 출고 · 배송 · 입금 · 세금계산서 · 장부 → 7 · 8 · 9장 곁가지 + 부록 「우리가 파는 것 한 장」
- **일 받았을 때** (`jobs.html`): 들은 말로 찾는 카드 열넷 — 현장 J1~J8 · 경리 J9~J14. 카드 한 장은 `job.html?c=j05`, 내용은 `jobs-data.js` 한 곳
- **이카운트 길잡이** (`ecount.html`): E0 이카운트 한 장 + 영업 · 창고 · 돈 · 세금 · 장부 · 구매 · 근태 · 급여 · 기초등록 길

부록의 블럼 리프트 줄에서 「3D로 보기」 → `hf-3d.html` (F자로 접힘(HF) 돌려 보기). 모형 `3d/hf.glb` 는 `3d/build_hf.py` 를 Blender 로 돌려 만든다 — `blender -b --factory-startup --python 3d/build_hf.py -- 3d`.

그림체는 연필 손그림 · 교과서 도식 · 설계 도면 세 가지 (주소 끝 `#pencil` · `#textbook` · `#blueprint`).
교재 · 길잡이 쪽은 `?k=5` 로 그 걸음을 열고 시작하고, `?from=j05` 면 「← 카드로」 가 붙는다 (카드의 꼬리표가 쓴다).
`(추정)` 은 실무자 확인 전, 「회사가 채움」 은 회사가 정할 자리. 주소는 회사 안에서만 나눈다.
