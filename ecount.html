이카운트 길잡이

어디서 무엇을 어떤 순서로 누르나. 먼저 한 장(E0)을 읽고, 맡은 일의 길로 간다. 상자를 누르면 그 길로.

E0 · 먼저이카운트 한 장계정 다섯 · 메뉴 다섯 묶음 · 입력 → 조회 → 현황 · 저장하면 바뀌는 것 · 틀렸을 때
현장물건이 움직이는 길
E1 · 영업견적서에서 거래명세서까지견적서 → 주문서 → 판매 → 거래명세서 · 수금 · 반품 E2 · 창고출하에서 실사까지출하지시 → 출하 → 창고이동 → 불량 · 자가사용 → 실사 → 재고현황 E5 · 구매발주서에서 입고까지단가요청 → 발주서 → 구매입력 → 미구매 → 채무 → 세트
경리돈과 장부의 길
E3 · 돈채권에서 입금까지거래처별채권 → 계좌 조회 → 입금보고서 → 지출결의서 → 대장 → 자금일보 E4 · 세금 · 장부회계반영에서 부가세까지회계반영 → 전표 → 세금계산서 발행 → 홈택스 비교 → 원장 → 부가세 E6 · 근태 · 급여출퇴근 기록에서 이체까지출퇴근 → 근태 · 휴가 → 결재 → 급여대장 → 이체 → 4대보험 E7 · 바닥거래처에서 단가까지기초등록 — 거래처 · 품목 · 창고 · 사원 · 단가 7가지 · 엑셀 올리기. 모든 길이 이 위에 선다

읽는 법

모양 길마다 화면 여섯. 상자 = 화면(칸 순서 · 저장 단추), 아래 화살표 = 누르는 단추, 오른쪽 점선 = 그 화면의 조회 · 현황(고치기 · 지우기 · 인쇄). 걸음마다 경로 · 넣는 칸 · 저장 뒤 · 조심 · 틀렸을 때 · 교재 쪽.

연습 회사가 정한 연습 거래처 · 연습 품목으로만. 세금계산서 발행은 연습 금지 — 국세청에 바로 간다 (E4).

교재와 잇기 윗층 1 · 2장 → E1 · E2, 4장 → E3, 5 · 6장 → E4, 7장 → E5 · E2, 9장 → E6, 0장 → E7.

초록 = 저장하면 재고 · 돈이 바뀌는 길 · 붉은 갈색 = 바깥(국세청 · 은행)으로 나가는 길 · 파랑 = 보고 맞추는 길

교재 = 이카운트 공식 교재(초급 재고 · 유통 / 중급 회계) · 회사 계정에만 있는 설정은 (추정) · 주소는 회사 안에서만 나눈다
